Red de Cómputo

Conjunto de equipos conectados entre sí que comparten recursos, información y servicios.

📶

LAN

LAN

Local Area Network. Red de área local que cubre un espacio físico limitado como una casa u oficina.

📦

Paquete

Paquete

Unidad de datos que viaja por la red. Contiene la información y la dirección IP de origen y destino.

🔌

Protocolo

Protocolo

Reglas que permiten la comunicación entre dispositivos. El estándar principal es TCP/IP.

IPv4 y Clases de Red

La Dirección IPv4 es un número de 32 bits (4 octetos) que identifica cada dispositivo en la red. Haz clic en cada clase para ver más detalles.

Estructura de una IPv4

192.168.1.15

Cuatro números del 0 al 255 separados por puntos. Cada uno es un octeto (8 bits) para un total de 32 bits.

Clases de Direcciones IPv4

Direccionamiento IP

Datos y conceptos clave para asignar direcciones correctamente en una red.

¿Qué es el Direccionamiento IP?

Es el proceso de asignar una dirección lógica única a cada dispositivo de la red para que pueda enviar y recibir datos correctamente.

IP Pública vs Privada

Pública: Visible en Internet (asignada por el ISP).
Privada: Uso interno en la LAN (no enrutable en Internet).

Rangos Privados (RFC 1918)

10.0.0.0 - 10.255.255.255
172.16.0.0 - 172.31.255.255
192.168.0.0 - 192.168.255.255

IP Estática vs Dinámica

Estática: Configurada manualmente (ideal para servidores e impresoras).
Dinámica: Asignada automáticamente por DHCP.
